# 2026-11-21 TIL: KEYUM (키음) 만들기

## 오늘 한 것

- 타자를 칠 때 컴퓨터 어디서든 피아노 소리가 나는 프로그램 **KEYUM**을 만들어서 GitHub에 올렸다.
- 저장소: https://github.com/minseo0812/keyum

## 배운 것

### 1. 전역 키 입력 받기 (`pynput`)

- `keyboard.Listener(on_press=..., on_release=...)`로 어느 앱에서 치든 키 입력을 감지할 수 있다.
- 키 이름 대신 **가상 키 코드(`vk`)**를 먼저 보면 Shift를 눌러도, 한글 입력 모드여도 같은 키로 인식한다.
- 키를 꾹 누르면 `on_press`가 반복돼서, 눌린 키를 `set`에 담아 반복을 막았다.
- 눌린 키는 저장하지 않고 소리만 재생한다. 전역 입력을 듣는 프로그램이라 이 점을 README에 적었다.

### 2. 소리 재생 (`pygame-ce`)

- Python 3.14에서는 `pygame` 대신 `pygame-ce`를 설치했다.
- 소리를 키마다 **미리 만들어 두고(`Sound`)** 누를 때 재생해야 반응이 빠르다.
- 채널을 64개로 늘려서 여러 소리를 동시에 울릴 수 있게 했다. `channel.set_volume`으로 칠 때마다 세기를 조금씩 다르게 했다.
- `AUDIO_BUFFER`를 키우면 지직거림이 줄고, 줄이면 반응이 빨라진다.

### 3. 소리 직접 만들기 (`numpy`)

- 음 번호(MIDI)를 주파수로: `440 * 2 ** ((midi - 69) / 12)`
- 사인파에 **배음**(2배, 3배 …)을 약하게 섞으면 피아노 같은 소리가 난다. 높은 배음일수록 약하게 해야 부드럽다.
- 같은 음을 아주 살짝 다른 주파수로 두 개 겹치면(디튠) 소리가 따뜻하고 풍성해진다.
- 시작을 `1 - exp(-t / ATTACK)`로 부드럽게 올리면 "띡" 하는 느낌이 줄어든다.
- 서서히 사라지는 잡음을 **컨볼루션(FFT)**으로 입히면 페달을 밟은 것 같은 울림(리버브)이 된다.

### 4. 소리가 찢어지는 이유: 클리핑

- 길게 울리는 소리가 겹치면 합이 최대치를 넘어서 "띡띡" 하는 잡음이 난다.
- 해결: 전체 볼륨 낮추기, 빨리 칠수록 새 소리를 작게 하기, 동시에 울리는 소리 개수 제한하기.

### 5. 아무렇게나 쳐도 어울리게: 음악 이론

- 도·레·미·파·솔·라·시(C 장조) 각 음 위에 **한 칸 건너 쌓은 3화음**을 만들었다. (도·미·솔, 레·파·라 …)
- 반음(1), 증4도(6), 장7도(11) 간격은 서로 부딪혀 들린다. 새 소리와 부딪히는 소리가 아직 울리고 있으면 서서히 줄였다.
- 아랫줄의 소리를 기준으로 가운데 줄은 1옥타브, 윗줄은 2옥타브 높게 같은 화음을 쓰니 줄마다 조율이 어긋나는 문제가 사라졌다.

## 막혔던 것과 해결

| 문제                                    | 원인                                 | 해결                                               |
| --------------------------------------- | ------------------------------------ | -------------------------------------------------- |
| `python keyum.py` 파일을 못 찾음        | 파일이 아직 없었다                   | `code keyum.py`로 만들기                           |
| `SyntaxError: '(' was never closed`     | 코드를 붙여넣다가 중간에 잘렸다      | 파일을 통째로 받아서 교체                          |
| `gh: command not found`                 | 설치는 됐지만 Git Bash가 경로를 모름 | `export PATH="$PATH:/c/Program Files/GitHub CLI"`  |
| `winget install -id` 오류               | 옵션은 하이픈 두 개                  | `winget install --id GitHub.cli`                   |
| `git status`에 홈 폴더 파일이 전부 나옴 | 홈 폴더 전체가 이미 git 저장소였다   | `keyum` 폴더에서 `git init`으로 따로 저장소 만들기 |

## Git / GitHub CLI 정리

```bash
gh auth login                       # 브라우저로 GitHub 로그인
git init
git add keyum.py README.md .gitignore requirements.txt
git commit -m "KEYUM 첫 버전"
gh repo create keyum --public --source=. --remote=origin --push
```

- `git status`로 **무엇이 올라가는지 먼저 확인**한다. 특히 홈 폴더 같은 곳에서는 `git add .`을 하지 않는다.
- `.gitignore`에 `.venv/`를 넣어서 가상환경은 올리지 않는다.
- `requirements.txt`에 패키지를 적어두면 `pip install -r requirements.txt` 한 줄로 설치할 수 있다.
